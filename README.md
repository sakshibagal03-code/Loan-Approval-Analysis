# Loan-Approval-Analysis EDA
Analysis of loan approval data, combining Exploratory Data Analysis (EDA) in Python with an interactive Power BI dashboard for clear, accessible insights.

This project explores a loan approval dataset to identify patterns and factors that influence approval decisions.  
It includes:
- Data cleaning, preprocessing and feature engineering.
- Exploratory analysis with pandas, matplotlib, and seaborn
- Visualizations of applicant demographics, income, credit history, and loan status
- Identification of key factors influencing loan approvals
- Clear narrative for both technical and non-technical audiences
- Integration of cleaned dataset into Power BI
- Interactive KPI dashboards with filters and drill-downs
- Visual storytelling of applicant trends and approval patterns
